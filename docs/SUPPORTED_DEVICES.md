# Supported Devices

Meow-ISP uses the bundled `vendor-wchisp` database. The database is compiled into
the binary from `vendor-wchisp/src/device.rs`, so the supported list below follows
the YAML files in `vendor-wchisp/devices`.

Total: 16 families, 85 variants.

Transport notes:

- The CLI can open USB or serial transport.
- The current desktop UI and `meowisp-core` high-level helpers are USB-first.
- CH32V00x is marked serial-only in the bundled database.
